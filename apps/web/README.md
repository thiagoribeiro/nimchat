# NimChat web

Next.js app of [NimChat](../../README.md). See the root README for setup, configuration
and tests.

This app started from a Next.js chat application tutorial by
[Antonio Erdeljac](https://github.com/AntonioErdeljac), as distributed under the MIT
License (see [LICENSE](LICENSE)). The original backend (Prisma, Clerk, Socket.io,
UploadThing, LiveKit) was replaced by `@nimchat/sdk` talking to Nimlet.
